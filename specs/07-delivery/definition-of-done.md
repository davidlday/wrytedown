# Definition of Done

A capability is done only when:

- Requirements and acceptance scenarios are approved.
- Domain and architecture effects are documented.
- Automated tests cover happy paths, failures, cancellation, and persistence.
- Accessibility checks pass for pointer and keyboard use.
- Security and privacy review is complete where applicable.
- Migration and recovery behavior are tested for storage changes.
- User-facing diagnostics and help text exist.
- Traceability links connect requirement, test, and release evidence.
