# Navigation and Focus Rules

1. One editor pane is active at a time.
2. Commands target the active selection when applicable; otherwise they target
   the active editor item.
3. Selecting in a navigation surface loads the active unlocked editor.
4. The inspector follows the active editor, not a background selection.
5. Each split owns independent history and view-mode preference.
6. Destructive actions show the exact target set.
7. Focus returns predictably after dialogs and transient panels close.
