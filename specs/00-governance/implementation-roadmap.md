# Implementation Roadmap

## Slice 1 — Durable project core

Project lifecycle, item model, tree operations, atomic save, recovery, and basic
text editor.

## Slice 2 — Authoring loop

Synopsis, status, word counts, combined view, search, and Trash restore.

## Slice 3 — Output loop

Compile selection, ordering, separators, Markdown/plain-text exporters, preview,
and export diagnostics.

## Slice 4 — Planning loop

Corkboard, outliner, labels, custom metadata, targets, and collections.

## Slice 5 — Advanced authoring

Splits, bookmarks, snapshots, comments, footnotes, styles, and revision tools.

## Slice 6 — Interchange and scale

Importers, richer exporters, backups, synchronization safeguards, extensions,
accessibility hardening, and performance validation.
