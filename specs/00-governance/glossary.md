# Glossary

- **Project**: persistent container for draft, research, metadata, settings, and
  UI state.
- **Binder**: hierarchical navigation view over project items.
- **Item**: addressable project node that may contain text, children, or both.
- **Container**: item currently used to organize child items.
- **Draft**: ordered root whose descendants are eligible for compilation.
- **Research**: root intended for supporting material.
- **Trash**: recoverable holding area for removed items.
- **Synopsis**: short summary associated with an item.
- **Collection**: named, non-destructive list or query result referencing items.
- **Combined view**: presentation of several text items as one continuous
  editing session.
- **Compile**: transform ordered source items into a chosen output format.
- **Snapshot**: immutable captured version of an item’s content at a point in
  time.
