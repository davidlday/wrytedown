# Scope and Release Boundaries

## MVP

- Create/open/save a project.
- Hierarchical item tree with text items and folders.
- Rich or structured text editing.
- Synopsis and core metadata per item.
- Draft, Research, and Trash system areas.
- Reorder items and preserve order.
- Single-item editor plus combined multi-item reading/editing.
- Search across title and text.
- Compile selected draft items to at least plain text and Markdown.
- Local backups and recovery validation.

## Post-MVP

- Corkboard, configurable outliner, split editors, copyholders.
- Saved layouts, collections, bookmarks, snapshots, custom metadata.
- Comments, footnotes, annotations, styles, revision workflows.
- Scriptwriting, advanced compile designer, templates, themes.
- Cloud-assisted workflows and external-folder synchronization.

## Explicit non-goals for MVP

- Feature parity with any existing commercial application.
- Real-time multi-user editing.
- Proprietary-format compatibility unless separately licensed and specified.
- Mobile clients.
