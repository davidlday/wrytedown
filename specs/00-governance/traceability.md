# Traceability Model

Use this chain:

`User need -> Capability -> FR/NFR -> Acceptance scenario -> Automated test -> Release evidence`

## Requirement ID prefixes

- `FR-PROJ`: projects and persistence
- `FR-PROJITEM`: item hierarchy
- `FR-EDIT`: editor
- `FR-VIEW`: visualizations and layouts
- `FR-META`: metadata and inspector
- `FR-NAV`: navigation and search
- `FR-ORG`: collections and organization
- `FR-WRITE`: writing tools
- `FR-COMP`: compile/export/print
- `FR-SYNC`: sharing and synchronization
- `NFR-*`: non-functional requirements
