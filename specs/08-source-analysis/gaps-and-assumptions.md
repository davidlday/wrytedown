# Gaps and Assumptions

## Source limitations

- The attached PDF content was available for analysis.
- The separate attached Wryte format specification could not be opened by the
  retrieval tool, so this pack does not claim compatibility with it.
- The manual is an exhaustive reference for a mature product; not every menu
  command or preference has been promoted to a first-class product requirement.

## Assumptions to validate

- The new project is a long-form writing application, not a byte-for-byte clone.
- Desktop and local-first are reasonable starting points.
- Project content should remain separate from output formatting.
- A hierarchy item may contain both text and children; this requires explicit
  product approval.
- The compile pipeline is strategically important enough to isolate
  architecturally.
