# Manual Coverage Map

The attached manual organizes the source product into five broad phases:
introduction/fundamentals, preparation and organization, writing, final output,
and appendices/reference.

## Mapping into this pack

- Projects, binder, files/folders -> `01-capabilities/projects/` and `items/`
- Editor and views -> `editor/` and `views/`
- Research, organization, search, navigation, inspector -> `research/`,
  `organization/`, `navigation/`, `metadata/`
- Writing, environments, styles, annotations, scriptwriting, tools -> `writing/`
- Table of contents, compile, export, print -> `output/`
- Settings, shortcuts, layouts, formats -> architecture, UX, and quality specs

## Method

The pack converts product behaviors into original, implementation-neutral
requirements. It deliberately omits step-by-step manual prose, screenshots,
branding, and other copyrighted expression.
