# ADR 0002: Editor Content Model

- **Status:** Proposed
- **Decision:** Choose Markdown-first, rich-text-first, or structured-document
  core.
- **Decision drivers:** fidelity, semantic styles, comments/footnotes, script
  elements, export formats, accessibility, and mergeability.
- **Required proof:** round-trip fixture suite covering Unicode, links, lists,
  tables, notes, inline marks, and pasted content.
